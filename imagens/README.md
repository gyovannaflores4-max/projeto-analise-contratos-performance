# Imagens do Dashboard

Esta pasta reúne as capturas finais das cinco páginas do relatório.

## Páginas

| Página | Arquivo | Objetivo |
|---|---|---|
| Visão Executiva | `visao_executiva.png` | resumir os principais KPIs financeiros e de carteira |
| Análise de Contratos | `análise de contratos.png` | acompanhar status, vencimentos e valor exposto |
| Especialidades e Serviços | `especialidades e serviços.png` | comparar volume, valor, SLA e criticidade |
| Performance e Qualidade | `performance e qualidade.png` | acompanhar indicadores operacionais ao longo do tempo |
| Qualidade dos Dados | `qualidade e dados.png` | demonstrar o processo de auditoria e validação |

As imagens também são exibidas no [README principal](../README.md), permitindo uma leitura rápida do projeto sem abrir o Power BI.
