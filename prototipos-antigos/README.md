# Protótipos antigos (não publicar)

Versões anteriores, guardadas só como referência de design. **Não fazem parte do site atual** e contêm promessas que não valem mais (por exemplo, pagamento em 24 horas e conta-custódia).

- `vidro.html`: versão com o template Clinic Liquid Glass (AnimatedWebs)
- `animado.html`: versão escura animada
- `lista-espera.html`: primeira página de lista de espera
- `demo/`: cópia do protótipo do app e do painel do hospital

O site atual fica na pasta `site/`.
